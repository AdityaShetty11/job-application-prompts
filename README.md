# job-application-prompts

Reusable prompts for creating a CV and cover letter tailored to a specific job posting and the applicant's profile.

## Prompts

- [Tailored CV](prompts/tailored-cv.md)
- [Tailored cover letter](prompts/tailored-cover-letter.md)

## How to use

1. Copy the prompt for the document you want to create.
2. Replace the input placeholders with the full job description and the applicant's up-to-date profile. Include an existing CV, relevant experience, skills, education, and any preferences or constraints.
3. Submit the completed prompt to your writing assistant and review the result for accuracy before using it.

The prompts use only information supplied in the profile. They are designed to emphasize relevant evidence without inventing qualifications, experience, or results.
